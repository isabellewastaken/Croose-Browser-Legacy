# Croose Browser Legacy
A browser utilising the WebBrowser component. Intended for Windows Vista to Windows 8.0.

This port was authorised by the original creator.
Note that not every website will work with the browser due to it being an old component using a slightly more limited version of the IE Engine that comes with your system. For Vista, that's IE 7-9. For 7, that's IE 10-11.

If you are using a modern version of Windows (e.g. Windows 10, its highly recommended you use the official version: https://github.com/her0347/Croose-Browser as WebView is compatible with these OS versions.

There is no official XP support as of now due to not having tested it well enough. If Windows XP will not start the browser, try OneCoreAPI, which will most likely allow a launch.

For the official modern website (downloads, etc) -->  https://tinyurl.com/croosebrowser
